⚡ Unit Converter

A modern Android Unit Converter application built with Java and Android Studio that enables quick and accurate conversions across multiple measurement categories through a clean, intuitive, and responsive user interface.

🚀 Features

* Convert units across multiple categories
* Modern dark-themed UI
* Instant conversion results
* Unit swap functionality
* Clear input and results
* Formatted output display
* Responsive mobile design
* Fast and lightweight conversion engine

📱 Supported Categories

* Length
* Weight
* Temperature
* Time
* Area
* Volume
* Speed
* Data Storage
* Energy
* Pressure

🛠️ Technologies Used

* Java
* Android Studio
* Android SDK
* XML
* Object-Oriented Programming (OOP)
* HashMap Data Structures

🏗️ Architecture

The application follows a simple modular structure:

* MainActivity.java – UI handling and user interactions
* ConversionUtils.java – Conversion logic and unit mappings
* activity_main.xml – User interface layout
* card_bg.xml – Custom UI styling

✨ Highlights

* Implemented support for 10 conversion categories
* Designed a custom dark-themed user interface
* Developed reusable conversion utilities for scalability
* Applied clean code and modular programming practices
* Optimized for smooth performance on Android devices
