# UnitConverter-Android

A simple Android Unit Converter application developed using Java and XML in Android Studio.

## Features
- Convert Centimeters (cm) to Meters (m)
- Convert Meters (m) to Kilometers (km)
- Convert Kilometers (km) to Centimeters (cm)
- User-friendly Android UI
- Built using Java and XML

## Technologies Used
- Java
- XML
- Android Studio
- Gradle
